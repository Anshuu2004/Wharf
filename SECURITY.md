# Security Policy

## Supported Versions

Wharf actively maintains and patches security vulnerabilities for the latest version on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

<br />

## Reporting a Vulnerability

The Wharf team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose findings.

If you believe you have discovered a security vulnerability in Wharf:

1. **Do NOT open a public GitHub issue.** Publicly disclosing a vulnerability puts all users at risk.
2. Email the maintainer directly at:
   - **Contact**: Pranav Khalate
   - **Email**: [pranav.kh25@gmail.com](mailto:pranav.kh25@gmail.com)
3. Include the following details in your report:
   - Description of the vulnerability and its potential impact.
   - Detailed step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
   - Any proposed mitigations or fixes if you have them.

<br />

## Response Process

- We will acknowledge receipt of your report within 48 hours.
- We will provide an assessment of the vulnerability and keep you updated on progress.
- Once a fix is verified and deployed, a public security advisory and release will be issued crediting your discovery (unless you request to remain anonymous).
